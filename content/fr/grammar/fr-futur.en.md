## The futur simple

Take the **infinitive** (drop the final *-e* of -re verbs) and add the endings — which look like *avoir* in the present:

| | parler | finir | prendre → prendr- |
|---|---|---|---|
| je | parler**ai** | finir**ai** | prendr**ai** |
| tu | parler**as** | finir**as** | prendr**as** |
| il / elle / on | parler**a** | finir**a** | prendr**a** |
| nous | parler**ons** | finir**ons** | prendr**ons** |
| vous | parler**ez** | finir**ez** | prendr**ez** |
| ils / elles | parler**ont** | finir**ont** | prendr**ont** |

## Irregular stems (same endings)

| | | | |
|---|---|---|---|
| être → **ser-** ([[je serai]]) | avoir → **aur-** ([[j'aurai]]) | aller → **ir-** ([[j'irai]]) | faire → **fer-** ([[je ferai]]) |
| venir → **viendr-** | voir → **verr-** | pouvoir → **pourr-** | vouloir → **voudr-** |
| devoir → **devr-** | savoir → **saur-** | falloir → **il faudra** | pleuvoir → **il pleuvra** |
| envoyer → **enverr-** | courir → **courr-** | recevoir → **recevr-** | tenir → **tiendr-** |

Spelling verbs keep their stressed change: *acheter → j'achèterai*, *appeler → j'appellerai*, *payer → je paierai*.

## Futur simple vs futur proche

| futur proche (aller + inf.) | futur simple |
|---|---|
| near, certain, already decided; very common in speech | predictions, promises, more distant or formal future |
| [[Je vais dîner chez Marc ce soir.]] | [[Un jour, je parlerai couramment français.]] |
| [[Attention, tu vas tomber !]] | [[Je t'appellerai demain, promis.]] |

## Quand + future

After **quand** (when), **lorsque, dès que** (as soon as), **aussitôt que**, French uses the **future** when the meaning is future (English uses the present!):
[[Quand je serai grand, je serai pilote.]] — When I grow up… · [[Je t'écrirai dès que j'arriverai.]]

But after **si** (if) — present: [[Si tu viens, on ira au cinéma.]]
