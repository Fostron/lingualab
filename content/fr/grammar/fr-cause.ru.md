## Причина

| | конструкция | оттенок | пример |
|---|---|---|---|
| **parce que** | + indicatif | отвечает на *pourquoi ?* | [[Je reste parce que je suis malade.]] — Я остаюсь, потому что болен. |
| **car** | + indicatif | письменное; не в начале фразы | [[Il est parti, car il était tard.]] — Он ушёл, так как было поздно. |
| **puisque** | + indicatif | причина известна, очевидна («раз уж») | [[Puisque tu insistes, je viens.]] — Раз ты настаиваешь, я приду. |
| **comme** | + indicatif | в начале фразы («так как») | [[Comme il faisait beau, on est sortis.]] |
| **étant donné que / vu que** | + indicatif | «учитывая, что» | [[Vu qu'il est tard, rentrons.]] |
| **grâce à** | + сущ. | положительная причина («благодаря») | [[Grâce à toi, j'ai réussi.]] |
| **à cause de** | + сущ. | отрицательная причина («из-за») | [[À cause de la grève, le train est annulé.]] |
| **en raison de** | + сущ. | официально, нейтрально («в связи с») | [[En raison des travaux, la route est fermée.]] |
| **faute de** | + сущ. / инф. | «за неимением» | [[Faute de temps, je n'ai pas fini.]] — Из-за нехватки времени я не закончил. |
| **sous prétexte que** | + indicatif | «под предлогом того, что» | |

## Следствие

| | пример |
|---|---|
| **donc** | [[Je pense, donc je suis.]] — Мыслю, следовательно, существую. |
| **alors** (разг.) | [[Il pleuvait, alors on est restés.]] |
| **c'est pourquoi / c'est pour ça que** | [[J'étais malade, c'est pourquoi je suis absent.]] — вот почему |
| **par conséquent / en conséquence** (книжн.) | [[Les prix augmentent ; par conséquent, on consomme moins.]] |
| **si bien que / de sorte que** + indicatif | [[Il a beaucoup plu, si bien que la rivière a débordé.]] — так что |
| **si / tellement + прил. + que** | [[Il était si fatigué qu'il s'est endormi.]] — Он так устал, что уснул. |
| **tant / tellement de + сущ. + que** | [[Il y avait tellement de monde que je suis parti.]] — Было столько народу, что я ушёл. |
| **d'où** + сущ. | отсюда: [[d'où mon retard]] — отсюда моё опоздание |

> **de sorte que + subjonctif** выражает **цель** («чтобы»), а не следствие: [[Parle fort, de sorte qu'on t'entende.]] — Говори громко, чтобы тебя услышали.
