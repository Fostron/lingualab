## Days of the week

[[lundi]] — Monday · [[mardi]] — Tuesday · [[mercredi]] — Wednesday · [[jeudi]] — Thursday · [[vendredi]] — Friday · [[samedi]] — Saturday · [[dimanche]] — Sunday. They are written in lowercase and are masculine.

- **no article** = this coming / last one: [[Je pars lundi.]] — I'm leaving on Monday.
- **le** + day = every week: [[Le lundi, je travaille.]] — On Mondays I work.
- [[le week-end]] · [[en semaine]] (on weekdays)

## Months and seasons

[[janvier]], [[février]], [[mars]], [[avril]], [[mai]], [[juin]], [[juillet]], [[août]], [[septembre]], [[octobre]], [[novembre]], [[décembre]] — lowercase. **en** + month: [[en mai]], or [[au mois de mai]].

Seasons: [[au printemps]] (in spring) but [[en été]], [[en automne]], [[en hiver]].

## Dates

**le** + cardinal number + month: [[le 14 juillet]], [[le 3 mai 2024]]. Only the 1st is an ordinal: [[le premier janvier]].
[[Quelle est la date aujourd'hui ?]] / [[On est le combien ?]] — [[Nous sommes le vingt mars.]] / [[On est le 20 mars.]]
Years: [[en 2024]] — *deux mille vingt-quatre*. [[Je suis né en 1995.]]

## Time words

| | |
|---|---|
| [[aujourd'hui]] | today |
| [[demain]] / [[après-demain]] | tomorrow / the day after tomorrow |
| [[hier]] / [[avant-hier]] | yesterday / the day before yesterday |
| [[le matin]] / [[l'après-midi]] / [[le soir]] / [[la nuit]] | morning / afternoon / evening / night |
| [[ce matin]], [[ce soir]] | this morning, tonight |
| [[la semaine prochaine]] / [[la semaine dernière]] | next week / last week |
| [[le mois prochain]], [[l'année dernière]] | next month, last year |

**jour / journée, an / année, soir / soirée, matin / matinée**: the short form is a point in time or a unit (with numbers: [[trois jours]], [[deux ans]]); the long form stresses the duration or content: [[toute la journée]] (all day long), [[Bonne soirée !]] (Have a nice evening!), [[l'année dernière]].
