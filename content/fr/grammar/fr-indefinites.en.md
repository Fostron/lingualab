## Someone / no one, something / nothing

| positive | negative |
|---|---|
| [[quelqu'un]] — someone | [[personne]] (ne) — no one |
| [[quelque chose]] — something | [[rien]] (ne) — nothing |
| [[quelque part]] — somewhere | [[nulle part]] (ne) — nowhere |
| [[toujours]] / [[parfois]] | [[jamais]] (ne) — never |

- [[Il y a quelqu'un ? — Non, il n'y a personne.]]
- [[Tu veux quelque chose ? — Non, je ne veux rien.]]
- As subjects: [[Personne n'est venu.]] [[Rien n'a changé.]]
- With an adjective: **de** + masculine adjective: [[quelque chose de bon]] (something good), [[rien d'intéressant]], [[quelqu'un de sympa]].

## Tout, tous, toute, toutes

| | |
|---|---|
| **tout le / toute la** + singular = the whole | [[tout le temps]] (all the time), [[toute la journée]] (all day) |
| **tous les / toutes les** + plural = all, every | [[tous les jours]] (every day), [[toutes les semaines]] |
| **tout** (pronoun) = everything | [[Tout va bien.]] [[J'ai tout compris.]] |
| **tous** (pronoun, *s* pronounced) = everyone | [[Ils sont tous là.]] |

## Chaque, chacun, plusieurs, certains, aucun

- **chaque** + singular noun (each, every): [[chaque jour]], [[chaque fois]]. **chacun / chacune** (each one): [[Chacun a son avis.]]
- **plusieurs** (several, invariable): [[plusieurs fois]], [[plusieurs amis]].
- **certains / certaines** (some, certain): [[Certains pensent que…]]
- **aucun / aucune … ne** (not a single, none): [[Je n'ai aucune idée.]] [[Aucun étudiant n'est venu.]]
