## Opinion → indicative, doubt → subjunctive

| affirming (indicative) | doubting / denying (subjunctive) |
|---|---|
| [[Je pense qu'il a raison.]] | [[Je ne pense pas qu'il ait raison.]] |
| [[Je crois que c'est vrai.]] | [[Je ne crois pas que ce soit vrai.]] |
| [[Je suis sûr qu'elle viendra.]] | [[Je ne suis pas sûr qu'elle vienne.]] |
| [[Il est certain que…]] / [[Il est évident que…]] | [[Il n'est pas certain que…]] |
| [[Il est probable que…]] | [[Il est possible que…]] / [[Il se peut que…]] |
| | [[Je doute que…]] |

The logic: *penser, croire, trouver, être sûr, il est clair / certain / évident / probable que* **assert** something → indicative. When negated (or in an inverted question), or with *douter, il est possible, il se peut*, the statement becomes uncertain → **subjunctive**.

- [[Je doute qu'il puisse venir.]] — I doubt he can come.
- [[Il est possible qu'il pleuve demain.]] — It may rain tomorrow.
- [[Penses-tu qu'il soit honnête ?]] (formal inverted question) vs [[Tu penses qu'il est honnête ?]] (everyday)

> Note the asymmetry: **il est probable que** + indicative (likely = almost certain) but **il est possible que** + subjunctive.

## Peut-être

**peut-être** (maybe) is an adverb and takes the **indicative**: [[Il viendra peut-être.]] / [[Peut-être qu'il viendra.]]

## It is the main verb that decides, not "que"

The mood depends on the **main verb**, not on *que*: [[Je sais que…]] (indicative), [[Je veux que…]] (subjunctive), [[Je ne pense pas que…]] (subjunctive).
