## Stressed pronouns

| subject | stressed |
|---|---|
| je | **moi** |
| tu | **toi** |
| il / elle | **lui** / **elle** |
| nous | **nous** |
| vous | **vous** |
| ils / elles | **eux** / **elles** |
| on | **soi** |

Use them:
1. **Alone or for emphasis**: [[Qui a fait ça ? — Moi !]] [[Moi, je préfère le thé.]] [[Lui, il est sympa.]]
2. **After prepositions**: [[avec moi]], [[pour toi]], [[chez lui]], [[sans eux]], [[à côté d'elle]].
3. **After c'est**: [[C'est moi.]] [[C'est lui qui l'a dit.]]
4. **In comparisons**: [[Il est plus grand que moi.]]
5. **With aussi / non plus**: [[Moi aussi.]] [[Toi non plus.]]
6. **With -même**: [[moi-même]] (myself), [[eux-mêmes]].
7. **To show possession with à**: [[Ce livre est à moi.]] — This book is mine.
8. **With verbs + à + person** that don't allow *lui/leur*: *penser à, s'intéresser à, faire attention à* — [[Je pense à toi.]]

## Possessive pronouns: mine, yours…

| | m. sing. | f. sing. | m. pl. | f. pl. |
|---|---|---|---|---|
| mine | **le mien** | **la mienne** | **les miens** | **les miennes** |
| yours (tu) | le tien | la tienne | les tiens | les tiennes |
| his / hers | le sien | la sienne | les siens | les siennes |
| ours | le nôtre | la nôtre | les nôtres | les nôtres |
| yours (vous) | le vôtre | la vôtre | les vôtres | les vôtres |
| theirs | le leur | la leur | les leurs | les leurs |

They agree with the **thing owned**: [[Ton vélo est rouge ; le mien est bleu.]] [[Ce n'est pas ma valise, c'est la sienne.]] (his **or** her suitcase)
Contractions: *à + le mien* → [[au mien]], *de + les leurs* → [[des leurs]].
