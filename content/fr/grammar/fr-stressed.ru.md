## Ударные местоимения

| подлежащее | ударная форма |
|---|---|
| je | **moi** |
| tu | **toi** |
| il / elle | **lui** / **elle** |
| nous | **nous** |
| vous | **vous** |
| ils / elles | **eux** / **elles** |
| on | **soi** |

Во французском подлежащее *je, tu, il* не может стоять отдельно или под ударением — для этого есть особые формы:
1. **Отдельно или для выделения**: [[Qui a fait ça ? — Moi !]] — Кто это сделал? — Я! [[Moi, je préfère le thé.]] — А я предпочитаю чай. [[Lui, il est sympa.]] — Он-то симпатичный.
2. **После предлогов**: [[avec moi]] — со мной, [[pour toi]] — для тебя, [[chez lui]] — у него, [[sans eux]] — без них, [[à côté d'elle]] — рядом с ней.
3. **После c'est**: [[C'est moi.]] — Это я. [[C'est lui qui l'a dit.]] — Это он сказал.
4. **В сравнениях**: [[Il est plus grand que moi.]] — Он выше меня.
5. **С aussi / non plus**: [[Moi aussi.]] — Я тоже. [[Toi non plus.]] — Ты тоже нет.
6. **С -même**: [[moi-même]] — я сам, [[eux-mêmes]] — они сами.
7. **Принадлежность с à**: [[Ce livre est à moi.]] — Эта книга моя.
8. **С глаголами + à + человек**, которые не допускают *lui/leur*: *penser à, s'intéresser à, faire attention à* — [[Je pense à toi.]] — Я думаю о тебе.

## Притяжательные местоимения: мой, твой (без существительного)

| | м. р. ед. ч. | ж. р. ед. ч. | м. р. мн. ч. | ж. р. мн. ч. |
|---|---|---|---|---|
| мой | **le mien** | **la mienne** | **les miens** | **les miennes** |
| твой | le tien | la tienne | les tiens | les tiennes |
| его / её | le sien | la sienne | les siens | les siennes |
| наш | le nôtre | la nôtre | les nôtres | les nôtres |
| ваш | le vôtre | la vôtre | les vôtres | les vôtres |
| их | le leur | la leur | les leurs | les leurs |

Они заменяют «притяжательное + существительное» и согласуются с **предметом**: [[Ton vélo est rouge ; le mien est bleu.]] — Твой велосипед красный, а мой синий. [[Ce n'est pas ma valise, c'est la sienne.]] — Это не мой чемодан, а его / её.
Слияние: *à + le mien* → [[au mien]], *de + les leurs* → [[des leurs]].
