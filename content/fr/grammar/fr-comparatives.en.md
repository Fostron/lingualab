## Comparing adjectives and adverbs

| | |
|---|---|
| **plus … que** (more … than) | [[Paris est plus grand que Lyon.]] |
| **moins … que** (less … than) | [[Ce livre est moins cher que l'autre.]] |
| **aussi … que** (as … as) | [[Elle est aussi grande que sa mère.]] |

The adjective agrees: [[Mes sœurs sont plus âgées que moi.]] After *que*, use stressed pronouns: *que moi, que toi, que lui, qu'elle*.
Adverbs work the same way: [[Il parle plus vite que moi.]] [[Je cours aussi vite que toi.]]

## Comparing nouns and verbs

**plus de / moins de / autant de + noun (+ que)**: [[J'ai plus de livres que toi.]] [[Il a autant d'amis que moi.]]
**verb + plus / moins / autant (que)**: [[Il travaille plus que moi.]] [[Je mange autant que lui.]]

## Irregular: bon → meilleur, bien → mieux

| | comparative | |
|---|---|---|
| **bon** (adjective, good) | **meilleur(e)** — better | [[Ce gâteau est meilleur.]] |
| **bien** (adverb, well) | **mieux** — better | [[Elle chante mieux que moi.]] |
| mauvais | **pire** or *plus mauvais* — worse | [[C'est pire.]] |

> **meilleur** describes a noun; **mieux** describes a verb. Never *plus bon* / *plus bien*.
[[C'est mieux !]] (That's better — about a situation) · [[Je me sens mieux.]] (I feel better)
