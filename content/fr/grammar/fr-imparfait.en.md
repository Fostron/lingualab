## Forming the imparfait

Take the **nous** form of the present, remove **-ons**, and add the endings:

| | parler (nous parl**ons**) | finir (nous finiss**ons**) |
|---|---|---|
| je | parl**ais** | finiss**ais** |
| tu | parl**ais** | finiss**ais** |
| il / elle / on | parl**ait** | finiss**ait** |
| nous | parl**ions** | finiss**ions** |
| vous | parl**iez** | finiss**iez** |
| ils / elles | parl**aient** | finiss**aient** |

*-ais, -ait, -aient* all sound the same (*è*). This rule works for almost every verb: faire → *nous faisons* → [[je faisais]]; prendre → [[je prenais]]; avoir → [[j'avais]].

**Only one exception — être**: [[j'étais]], tu étais, il était, nous étions, vous étiez, ils étaient.
Spelling: *manger → je mangeais, nous mangions*; *commencer → je commençais*.

## When to use it

1. **Descriptions** in the past (people, places, weather, feelings, age): [[Il faisait beau.]] [[La maison était grande.]] [[J'avais dix ans.]] [[Elle était triste.]]
2. **Habits** — *used to / would*: [[Quand j'étais petit, je jouais au foot tous les jours.]]
3. **Actions in progress** — *was doing*: [[Je lisais quand tu as appelé.]]
4. **Polite requests**: [[Je voulais vous demander quelque chose.]]
5. **Suggestions** with *si*: [[Et si on allait au cinéma ?]] — How about going to the cinema?

Signal words: [[autrefois]] (in the past), [[avant]], [[d'habitude]] (usually), [[souvent]], [[toujours]], [[tous les jours]], [[chaque été]], [[quand j'étais petit]], [[pendant que]] (while)
