## Глаголы, спрягающиеся с être

Около 15 глаголов — в основном глаголы **движения и изменения состояния** — образуют passé composé не с avoir, а с **être**. Их нужно выучить:

| глагол | причастие | | глагол | причастие |
|---|---|---|---|---|
| aller — идти | [[allé]] | | venir — приходить | [[venu]] |
| arriver — прибывать | [[arrivé]] | | partir — уезжать | [[parti]] |
| entrer — входить | [[entré]] | | sortir — выходить | [[sorti]] |
| monter — подниматься | [[monté]] | | descendre — спускаться | [[descendu]] |
| naître — родиться | [[né]] | | mourir — умереть | [[mort]] |
| rester — оставаться | [[resté]] | | tomber — упасть | [[tombé]] |
| retourner — вернуться | [[retourné]] | | passer (par) — пройти | [[passé]] |

и производные: **revenir, rentrer, devenir, repartir**…

**Все местоименные глаголы** тоже спрягаются с être: [[Je me suis levé.]] — Я встал. [[Elle s'est habillée.]] — Она оделась.

## Согласование

С **être** причастие **согласуется с подлежащим**, как прилагательное: **+e** для женского рода, **+s** для множественного. Это как русское «пошёл / пошла / пошли»:

| | |
|---|---|
| je suis allé(e) | nous sommes allé(e)s |
| tu es allé(e) | vous êtes allé(e)(s) |
| il est allé / elle est allée | ils sont allés / elles sont allées |

- [[Marie est arrivée hier.]] — Мари приехала вчера.
- [[Nous sommes partis à huit heures.]] — Мы уехали в восемь.
- [[Elles sont restées à la maison.]] — Они остались дома.
- [[Je suis né en 1990.]] / [[Je suis née en 1990.]] (если пишет женщина)
- [[Ils se sont rencontrés à Paris.]] — Они познакомились в Париже.

> Женщине нужно согласовывать о себе: *je suis allé**e***, *je suis né**e***, *je me suis levé**e***.

## С прямым дополнением → avoir

*monter, descendre, sortir, rentrer, passer, retourner* спрягаются с **avoir**, если у них есть прямое дополнение:
[[Je suis sorti.]] — Я вышел. / [[J'ai sorti le chien.]] — Я вывел собаку. · [[Elle est montée.]] — Она поднялась. / [[Elle a monté les valises.]] — Она подняла чемоданы.
