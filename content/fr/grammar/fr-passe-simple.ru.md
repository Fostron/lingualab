**Passé simple** — повествовательное прошедшее время письменного французского: романы, сказки, учебники истории, биографии. В разговоре его не используют (его заменяет passé composé), но для чтения литературы его нужно **узнавать**.

## Формы

| | -er: parler | -ir/-re: finir, vendre | тип на -u: avoir, être |
|---|---|---|---|
| je | parl**ai** | fin**is**, vend**is** | **eus**, **fus** |
| tu | parl**as** | fin**is** | eus, fus |
| il / elle | parl**a** | fin**it**, vend**it** | **eut**, **fut** |
| nous | parl**âmes** | fin**îmes** | eûmes, fûmes |
| vous | parl**âtes** | fin**îtes** | eûtes, fûtes |
| ils / elles | parl**èrent** | fin**irent**, vend**irent** | **eurent**, **furent** |

На практике встречается в основном **3-е лицо**: *il parla, ils parlèrent; il fit, ils firent; il fut, ils furent*.

## Частые неправильные формы (3-е лицо ед. / мн. ч.)

| | | |
|---|---|---|
| faire → [[il fit]] / ils firent | dire → [[il dit]] / ils dirent | voir → [[il vit]] / ils virent |
| prendre → [[il prit]] / ils prirent | mettre → [[il mit]] / ils mirent | venir → [[il vint]] / ils vinrent |
| pouvoir → [[il put]] / ils purent | vouloir → [[il voulut]] | savoir → [[il sut]] |
| naître → [[il naquit]] | mourir → [[il mourut]] | vivre → [[il vécut]] |
| aller → [[il alla]] / ils allèrent | écrire → [[il écrivit]] | tenir → [[il tint]] |

> Осторожно: *il fit* (сделал) и *il fut* (был), *il vit* (увидел — passé simple от *voir*, и живёт — présent от *vivre*!) — смысл подсказывает контекст.

## Passé simple + imparfait в повествовании

Как passé composé + imparfait: passé simple передаёт **события**, imparfait — **фон**:
[[Il était une fois une princesse qui vivait dans un château. Un jour, un prince arriva. Il la vit et tomba amoureux.]] — Жила-была принцесса… Однажды приехал принц. Он увидел её и влюбился.
