Местоименные глаголы (с *se*) имеют четыре разных значения — почти как русские глаголы на «-ся». Различать их важно и для смысла, и для согласования причастия.

## 1. Возвратное — действие направлено на себя

[[Je me lave.]] — Я моюсь. · [[Elle se regarde dans le miroir.]] — Она смотрится в зеркало. · [[Il s'est coupé.]] — Он порезался.

## 2. Взаимное — «друг друга» (подлежащее во мн. ч.)

[[Ils s'aiment.]] — Они любят друг друга. · [[Nous nous écrivons souvent.]] — Мы часто переписываемся. · [[On se voit demain ?]] — Увидимся завтра? · [[Ils se sont disputés.]] — Они поссорились.
Для ясности добавляют *l'un l'autre / mutuellement*: [[Ils se regardent l'un l'autre.]]

## 3. Страдательное значение — общие факты, правила, привычки

[[Ce plat se mange froid.]] — Это блюдо едят холодным. · [[Ça se voit.]] — Это видно. · [[Le français se parle dans 30 pays.]] — На французском говорят в 30 странах. · [[Ça ne se fait pas.]] — Так не делают.

## 4. Собственно местоименные — существуют только с se или меняют смысл

| только с se | смысл меняется |
|---|---|
| [[se souvenir de]] — помнить | [[douter]] (сомневаться) / [[se douter de]] (догадываться) |
| [[s'enfuir]] — убежать | [[apercevoir]] (заметить) / [[s'apercevoir de]] (осознать) |
| [[se moquer de]] — насмехаться | [[attendre]] (ждать) / [[s'attendre à]] (ожидать, предполагать) |
| [[s'évanouir]] — упасть в обморок | [[rendre]] (возвращать) / [[se rendre]] (отправиться; сдаться) |
| [[se méfier de]] — не доверять | [[passer]] (проходить) / [[se passer]] (происходить); [[se passer de]] (обходиться без) |
| [[s'en aller]] — уходить | [[tromper]] (обманывать) / [[se tromper]] (ошибаться) |

## Se faire, se laisser, se voir + инфинитив

Выражают то, что **происходит с** подлежащим (оттенок пассива):
- [[Il s'est fait arrêter.]] — Его арестовали.
- [[Elle s'est laissé convaincre.]] — Она дала себя уговорить.
- [[Il s'est vu refuser l'entrée.]] — Ему отказали во входе.
- [[Je me suis fait avoir.]] (разг.) — Меня обманули / развели.
