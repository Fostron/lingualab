## Expressing cause

| | construction | nuance | example |
|---|---|---|---|
| **parce que** | + indicative | answers *pourquoi ?* | [[Je reste parce que je suis malade.]] |
| **car** | + indicative | written; never at the start | [[Il est parti, car il était tard.]] |
| **puisque** | + indicative | the cause is known / obvious | [[Puisque tu insistes, je viens.]] |
| **comme** | + indicative | at the start of the sentence | [[Comme il faisait beau, on est sortis.]] |
| **étant donné que / vu que** | + indicative | given that | [[Vu qu'il est tard, rentrons.]] |
| **grâce à** | + noun | positive cause | [[Grâce à toi, j'ai réussi.]] |
| **à cause de** | + noun | negative cause | [[À cause de la grève, le train est annulé.]] |
| **en raison de** | + noun | formal, neutral | [[En raison des travaux, la route est fermée.]] |
| **faute de** | + noun / inf. | for lack of | [[Faute de temps, je n'ai pas fini.]] |
| **sous prétexte que** | + indicative | on the pretext that | |

## Expressing consequence

| | example |
|---|---|
| **donc** | [[Je pense, donc je suis.]] |
| **alors** (spoken) | [[Il pleuvait, alors on est restés.]] |
| **c'est pourquoi / c'est pour ça que** | [[J'étais malade, c'est pourquoi je suis absent.]] |
| **par conséquent / en conséquence** (formal) | [[Les prix augmentent ; par conséquent, on consomme moins.]] |
| **si bien que / de sorte que** + indicative | [[Il a beaucoup plu, si bien que la rivière a débordé.]] |
| **si / tellement + adj. + que** | [[Il était si fatigué qu'il s'est endormi.]] — so tired that… |
| **tant / tellement de + noun + que** | [[Il y avait tellement de monde que je suis parti.]] |
| **d'où** + noun | hence: [[d'où mon retard]] |

> **de sorte que + subjunctive** expresses **purpose** (so that) rather than consequence: [[Parle fort, de sorte qu'on t'entende.]]
