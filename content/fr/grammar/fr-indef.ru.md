## Неопределённый артикль

| | ед. ч. | мн. ч. |
|---|---|---|
| м. р. | **un** — [[un livre]] | **des** — [[des livres]] |
| ж. р. | **une** — [[une maison]] | **des** — [[des maisons]] |

*Un / une* — это «какой-то, один, некий»: предмет упоминается впервые или не важно, какой именно. Во множественном числе нужен **des** (по-русски «какие-то, несколько» обычно не говорим): [[J'ai des livres.]] — У меня есть книги.

## Определённый или неопределённый?

Сравните: [[Il y a un café dans la rue. Le café est très bon.]] — На улице есть (какое-то) кафе. Это кафе очень хорошее.
- **un / une / des** — новое, любое, «один из»;
- **le / la / les** — уже известное, конкретное или единственное.

Перед профессией и национальностью после *être* артикль не ставится: [[Il est médecin.]] — Он врач.

## un / une / des → de в отрицании

После отрицания неопределённый (и частичный) артикль превращается в **de / d'** («нет никакого»):
- [[J'ai un chien.]] → [[Je n'ai pas de chien.]] — У меня нет собаки.
- [[Il y a des enfants.]] → [[Il n'y a pas d'enfants.]]

Но после *être* артикль сохраняется: [[Ce n'est pas un livre, c'est un cahier.]]

## Множественное число существительных

| правило | пример |
|---|---|
| + **-s** (не читается) | [[une maison]] → [[des maisons]] |
| на **-s, -x, -z** — без изменений | [[un fils]] → [[des fils]], [[un prix]] → [[des prix]] |
| **-eau, -eu** → **-x** | [[un bateau]] → [[des bateaux]], [[un jeu]] → [[des jeux]] |
| **-al** → **-aux** | [[un journal]] → [[des journaux]], [[un animal]] → [[des animaux]] |
| исключения | [[un œil]] → [[des yeux]] (глаз — глаза), [[monsieur]] → [[messieurs]] |

> Окончание -s не произносится, поэтому на слух число различают по артиклю: *le livre* [лё] — *les livres* [ле].
