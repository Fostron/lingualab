Идиомы оживляют французскую речь. Эти выражения часто встречаются в разговоре, кино и прессе. Обратите внимание на русские соответствия — образы часто совсем другие.

## С частями тела

| идиома | значение |
|---|---|
| [[avoir le cafard]] | хандрить (досл. «иметь таракана») |
| [[coûter les yeux de la tête]] | стоить бешеных денег |
| [[mettre les pieds dans le plat]] | сболтнуть лишнее, ляпнуть |
| [[avoir un poil dans la main]] | быть лентяем |
| [[casser les pieds à quelqu'un]] | надоедать, доставать кого-то |
| [[se mettre le doigt dans l'œil]] | глубоко ошибаться, попасть пальцем в небо |
| [[ne pas avoir la langue dans sa poche]] | за словом в карман не лезть |
| [[tenir la jambe à quelqu'un]] | заговорить кого-то, не отпускать |
| [[avoir la tête dans les nuages]] | витать в облаках |
| [[faire la tête]] | дуться |
