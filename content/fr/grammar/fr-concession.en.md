## Concession: although / even though / despite

| | construction | example |
|---|---|---|
| **bien que / quoique** | + subjunctive | [[Bien qu'il soit fatigué, il continue.]] |
| **même si** | + indicative | [[Même s'il pleut, je sortirai.]] — Even if it rains… |
| **malgré** | + noun | [[Malgré la pluie, nous sommes sortis.]] |
| **malgré le fait que** | + subj./ind. | [[Malgré le fait qu'il soit jeune…]] |
| **pourtant / cependant / toutefois / néanmoins** | adverbs linking two clauses | [[Il est riche ; pourtant, il vit simplement.]] |
| **avoir beau + infinitive** | *however much* | [[J'ai beau chercher, je ne trouve pas mes clés.]] — However hard I look… |
| **quand même / tout de même** | *all the same, anyway* | [[Il pleut, mais je sors quand même.]] |
| **même** + adjective/participle | *even though* | [[Même fatigué, il a continué.]] |
| **quel que soit / quoi que / qui que / où que** | *whatever / whoever / wherever* + subj. | [[Quelle que soit ta décision, je te soutiendrai.]] [[Quoi que tu fasses…]] |

> **quoique** (although, + subj.) ≠ **quoi que** (whatever, + subj.): [[Quoique malade, il travaille.]] / [[Quoi qu'il arrive, reste calme.]]

## Opposition: whereas / on the other hand

| | |
|---|---|
| **alors que / tandis que** + ind. | [[Il travaille, alors que moi, je me repose.]] |
| **au lieu de** + inf. / noun | instead of — [[Au lieu de regarder la télé, lis un livre.]] |
| **par contre** (spoken) / **en revanche** (written) | [[Le restaurant est cher ; en revanche, la cuisine est excellente.]] |
| **au contraire** | on the contrary |
| **contrairement à** | unlike — [[Contrairement à son frère, il est timide.]] |
