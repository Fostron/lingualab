Idioms make French come alive. These are common in everyday speech, films and the press.

## With the body

| idiom | meaning |
|---|---|

| [[coûter les yeux de la tête]] | to cost an arm and a leg |
| [[mettre les pieds dans le plat]] | to put one's foot in it |
| [[avoir un poil dans la main]] | to be lazy |
| [[casser les pieds à quelqu'un]] | to annoy someone |
| [[se mettre le doigt dans l'œil]] | to be completely wrong |
| [[ne pas avoir la langue dans sa poche]] | to be outspoken |
| [[tenir la jambe à quelqu'un]] | to keep someone talking |
| [[avoir la tête dans les nuages]] | to have one's head in the clouds |
