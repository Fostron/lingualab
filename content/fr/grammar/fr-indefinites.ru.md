## Кто-то / никто, что-то / ничего

| утверждение | отрицание |
|---|---|
| [[quelqu'un]] — кто-то, кто-нибудь | [[personne]] (ne) — никто |
| [[quelque chose]] — что-то, что-нибудь | [[rien]] (ne) — ничего |
| [[quelque part]] — где-то, куда-то | [[nulle part]] (ne) — нигде, никуда |
| [[toujours]] / [[parfois]] | [[jamais]] (ne) — никогда |

- [[Il y a quelqu'un ? — Non, il n'y a personne.]] — Есть кто-нибудь? — Нет, никого.
- [[Tu veux quelque chose ? — Non, je ne veux rien.]] — Хочешь что-нибудь? — Нет, ничего.
- В роли подлежащего: [[Personne n'est venu.]] — Никто не пришёл. [[Rien n'a changé.]] — Ничего не изменилось.
- С прилагательным — **de** + прил. в м. р.: [[quelque chose de bon]] — что-то вкусное, [[rien d'intéressant]] — ничего интересного, [[quelqu'un de sympa]] — кто-то симпатичный.

> В русском «никто не пришёл» — двойное отрицание, во французском тоже: **personne ne**, но без *pas*.

## Tout, tous, toute, toutes — весь, все, всё

| | |
|---|---|
| **tout le / toute la** + ед. ч. = весь, целый | [[tout le temps]] — всё время, [[toute la journée]] — весь день |
| **tous les / toutes les** + мн. ч. = все, каждый | [[tous les jours]] — каждый день, [[toutes les semaines]] |
| **tout** (местоимение) = всё | [[Tout va bien.]] — Всё хорошо. [[J'ai tout compris.]] — Я всё понял. |
| **tous** (местоимение, *s* читается) = все | [[Ils sont tous là.]] — Они все здесь. |

## Chaque, chacun, plusieurs, certains, aucun

- **chaque** + ед. ч. — каждый: [[chaque jour]], [[chaque fois]]. **chacun / chacune** — каждый (без сущ.): [[Chacun a son avis.]] — У каждого своё мнение.
- **plusieurs** — несколько (не изменяется): [[plusieurs fois]], [[plusieurs amis]].
- **certains / certaines** — некоторые: [[Certains pensent que…]]
- **aucun / aucune … ne** — ни один: [[Je n'ai aucune idée.]] — Понятия не имею. [[Aucun étudiant n'est venu.]]
