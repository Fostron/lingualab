## Passé composé — основное прошедшее время

Passé composé описывает **законченные действия в прошлом** — что произошло, что было сделано. Это ближе всего к русскому **совершенному виду** прошедшего времени: «сделал, сказал, посмотрел».

**avoir (в настоящем) + причастие прошедшего времени**

| | |
|---|---|
| j'**ai** mangé | nous **avons** mangé |
| tu **as** mangé | vous **avez** mangé |
| il / elle / on **a** mangé | ils / elles **ont** mangé |

## Правильные причастия

| тип глагола | причастие | пример |
|---|---|---|
| -er | **-é** | parler → [[parlé]], manger → [[mangé]] |
| -ir (как finir) | **-i** | finir → [[fini]], choisir → [[choisi]] |
| -re | **-u** | vendre → [[vendu]], attendre → [[attendu]] |

## Неправильные причастия (очень частые!)

| | | | |
|---|---|---|---|
| avoir → [[eu]] | être → [[été]] | faire → [[fait]] | dire → [[dit]] |
| prendre → [[pris]] | mettre → [[mis]] | écrire → [[écrit]] | voir → [[vu]] |
| boire → [[bu]] | lire → [[lu]] | pouvoir → [[pu]] | vouloir → [[voulu]] |
| devoir → [[dû]] | savoir → [[su]] | connaître → [[connu]] | ouvrir → [[ouvert]] |
| recevoir → [[reçu]] | vivre → [[vécu]] | croire → [[cru]] | courir → [[couru]] |

## Примеры

- [[Hier, j'ai travaillé jusqu'à huit heures.]] — Вчера я работал до восьми.
- [[Tu as vu ce film ?]] — Ты смотрел этот фильм?
- [[Nous avons pris le train.]] — Мы поехали на поезде.
- [[Ils ont fini leurs devoirs.]] — Они сделали домашнее задание.
- [[Elle a eu un accident.]] — Она попала в аварию.

## Отрицание и порядок слов

*ne … pas* обрамляет **вспомогательный глагол**: [[Je n'ai pas mangé.]] — Я не ел. [[Il n'a jamais vu la mer.]] — Он никогда не видел моря.
Короткие наречия — между вспомогательным глаголом и причастием: [[J'ai déjà fini.]] — Я уже закончил. [[Tu as bien dormi ?]] [[Je n'ai pas encore lu ce livre.]]
Местоимения-дополнения — перед вспомогательным: [[Je l'ai vu.]] — Я его видел.
