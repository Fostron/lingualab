Knowing how words are built lets you understand — and create — thousands of words.

## Diminutives

Express smallness, affection, or politeness. The most common is **-ito / -ita**:
[[casa]] → [[casita]], [[perro]] → [[perrito]], [[abuela]] → [[abuelita]], [[ahora]] → [[ahorita]] (right now — Lat. Am.), [[un momentito]], [[un poquito]].
- Words ending in -e, -n, -r: **-cito**: [[café]] → [[cafecito]], [[joven]] → [[jovencito]], [[amor]] → [[amorcito]].
- Spelling: *poco → poquito, amigo → amiguito, pedazo → pedacito*.
- Regional: **-illo** (Andalusia): [[pajarillo]]; **-ico** (Aragón, Costa Rica): [[momentico]]; **-ín** (Asturias): [[pequeñín]].

## Augmentatives and pejoratives

**-ón / -ona** (big): [[casona]], [[cabezón]] (big-headed / stubborn), [[mujerona]], [[un notición]] (big news).
**-azo / -aza**: big or great ([[cochazo]] — amazing car) and also a blow: [[portazo]] (door slam), [[codazo]] (elbow jab), [[balonazo]].
**-ucho / -uza**, **-ajo**: pejorative: [[casucha]] (hovel), [[gentuza]] (riff-raff), [[pequeñajo]].

## Common suffixes

| suffix | meaning | examples |
|---|---|---|
| -ero/-era | profession, container | [[zapatero]], [[panadero]], [[azucarero]] |
| -ería | shop | [[zapatería]], [[panadería]], [[librería]] |
| -dor/-dora | agent, machine | [[trabajador]], [[ordenador]], [[lavadora]] |
| -ción / -sión | action → noun | [[organizar]] → [[organización]] |
| -miento | action → noun | [[conocer]] → [[conocimiento]] |
| -dad / -tad | quality | [[feliz]] → [[felicidad]], [[libre]] → [[libertad]] |
| -eza | quality | [[bello]] → [[belleza]], [[triste]] → [[tristeza]] |
| -ble | possible to | [[comer]] → [[comestible]], [[creer]] → [[creíble]] |
| -oso | full of | [[peligro]] → [[peligroso]], [[ruido]] → [[ruidoso]] |

## Prefixes

[[des-]] (un-, dis-): [[deshacer]], [[desconocido]] · [[in-]] / [[im-]] / [[i-]]: [[imposible]], [[ilegal]], [[irresponsable]] · [[re-]] (again): [[releer]], [[rehacer]] · [[pre-]]: [[prever]] · [[sobre-]] (over): [[sobrevivir]] · [[sub-]]: [[subterráneo]] · [[anti-]] · [[ex-]] · [[super-]] / [[re-]] (colloquial "very"): [[superfácil]], [[rebueno]] · [[mal-]]: [[malentendido]]

## Compounds

verb + noun (always masculine): [[el abrelatas]] (can opener), [[el sacacorchos]], [[el paraguas]], [[el lavaplatos]], [[el rascacielos]] (skyscraper), [[el cumpleaños]].
