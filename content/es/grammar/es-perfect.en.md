## Present perfect: he hablado

**haber** (present) + **past participle**:

| haber | + participle |
|---|---|
| yo **he** | hablado |
| tú **has** | comido |
| él/ella/Ud. **ha** | vivido |
| nosotros **hemos** | |
| vosotros **habéis** | |
| ellos/Uds. **han** | |

**Participles:** -ar → **-ado** ([[hablado]]), -er / -ir → **-ido** ([[comido]], [[vivido]]). The participle never changes after *haber*, and nothing goes between *haber* and the participle: [[No lo he visto.]]

## Irregular participles (learn these!)

| | | | |
|---|---|---|---|
| hacer → [[hecho]] | decir → [[dicho]] | ver → [[visto]] | escribir → [[escrito]] |
| poner → [[puesto]] | volver → [[vuelto]] | abrir → [[abierto]] | romper → [[roto]] |
| morir → [[muerto]] | descubrir → [[descubierto]] | resolver → [[resuelto]] | ir → [[ido]] |

Vowel + -ído: leer → [[leído]], oír → [[oído]], traer → [[traído]].

## When to use it

1. **Experiences** (ever / never): [[¿Has estado en México? — No, nunca he estado allí.]]
2. Actions in a **time period that is still open**: [[Hoy he trabajado mucho.]] [[Esta semana hemos ido al cine dos veces.]] [[Este año he viajado poco.]]
3. **Recent past** with present relevance (especially in Spain): [[¿Qué ha pasado?]] [[He perdido las llaves.]]
4. With **ya** (already), **todavía no / aún no** (not yet), **nunca**, **alguna vez** (ever): [[Ya he comido.]] [[Todavía no he terminado.]]

## Present perfect vs preterite

| present perfect (period not over) | preterite (period over) |
|---|---|
| [[Hoy he visto a Juan.]] | [[Ayer vi a Juan.]] |
| [[Este mes he leído tres libros.]] | [[El mes pasado leí tres libros.]] |

> In most of **Latin America** the preterite is used even for "today" and recent events: *¿Qué pasó?* instead of *¿Qué ha pasado?* Both are correct; Spain prefers the perfect for today.
