## Reacting to something with feelings

When you express an **emotion or value judgment about another person's action**, that action goes into the **subjunctive** — even if it's a fact.

- [[Me alegro de que estés aquí.]] — I'm glad (that) you're here.
- [[Siento que no puedas venir.]] — I'm sorry you can't come.
- [[Me molesta que hables tan alto.]] — It bothers me that you talk so loud.
- [[Me sorprende que no lo sepas.]]
- [[Tengo miedo de que llueva.]] — I'm afraid it'll rain.
- [[Es una pena que te vayas.]] — It's a pity you're leaving.
- [[Me encanta que me escribas.]]

Common triggers:
| | |
|---|---|
| alegrarse de que | to be glad that |
| sentir que | to be sorry that |
| tener miedo de que / temer que | to be afraid that |
| me gusta / encanta / molesta / sorprende / preocupa que | I like / love / am bothered / surprised / worried that |
| estar contento / harto / orgulloso de que | to be happy / fed up / proud that |
| es una pena / lástima que | it's a pity that |
| ¡Qué bien / pena / raro que…! | How nice / sad / strange that…! |

[[¡Qué bien que hayas venido!]] — How nice that you came! (perfect subjunctive — B2)

## Same subject → infinitive

| | |
|---|---|
| [[Me alegro de estar aquí.]] — I'm glad to be here. (I am here) | [[Me alegro de que estés aquí.]] — I'm glad you're here. |
| [[Siento llegar tarde.]] — I'm sorry I'm late. | [[Siento que llegues tarde.]] |

> With *gustar*-type verbs, the infinitive is used when the same person feels and acts: [[Me gusta bailar.]] / [[Me gusta que bailes.]]
