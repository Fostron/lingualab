## Negative commands

**All negative commands use the present subjunctive** — including *tú* and *vosotros*:

| | affirmative | negative |
|---|---|---|
| tú | habla, come | **no hables**, **no comas** |
| usted | hable, coma | no hable, no coma |
| nosotros (let's) | hablemos | no hablemos |
| vosotros | hablad, comed | **no habléis**, **no comáis** |
| ustedes | hablen, coman | no hablen, no coman |

Irregular *tú* commands lose their irregularity in the negative: *ven* → [[no vengas]], *haz* → [[no hagas]], *di* → [[no digas]], *ve* → [[no vayas]], *pon* → [[no pongas]], *sal* → [[no salgas]], *sé* → [[no seas]], *ten* → [[no tengas]].

- [[¡No toques eso!]] — Don't touch that!
- [[No te preocupes.]] — Don't worry.
- [[No llegues tarde.]]
- [[No seáis tontos.]]

## Pronoun position

| affirmative: **attached** | negative: **before the verb** |
|---|---|
| [[Dímelo.]] | [[No me lo digas.]] |
| [[Siéntate.]] | [[No te sientes.]] |
| [[Cómpralo.]] | [[No lo compres.]] |
| [[Levántense.]] | [[No se levanten.]] |

Attached pronouns often require a written accent to keep the stress: *compra → cómpralo, dime → dímelo*.

## Let's: nosotros commands

**Let's + verb** = subjunctive *nosotros*: [[Hablemos.]] [[Comamos aquí.]] (or *Vamos a + infinitive*). With *nos*, drop the final *-s*: *sentemos + nos* → [[Sentémonos.]] Exception: **ir** → [[¡Vamos!]] / [[¡Vámonos!]] — Let's go!

## Softening commands

Spanish commands are not rude in themselves, but these are softer: [[¿Puedes…?]], [[¿Me pasas…?]], [[¿Te importaría…?]], or the present tense: [[Me pones un café, por favor.]]
