## The rules in one place

Object pronouns (*me, te, lo, la, le, nos, os, los, las, les, se*) go:

| verb form | position | example |
|---|---|---|
| conjugated verb | **before**, as separate words | [[Te lo digo.]] [[No se lo he dicho.]] |
| affirmative command | **attached** | [[Dímelo.]] [[Siéntense.]] |
| negative command | **before** | [[No me lo digas.]] |
| infinitive | attached **or** before the conjugated verb | [[Quiero decírtelo.]] = [[Te lo quiero decir.]] |
| gerund | attached **or** before *estar* | [[Estoy haciéndolo.]] = [[Lo estoy haciendo.]] |
| compound tense (haber + participle) | before *haber* — never attached to the participle | [[Lo he visto.]] (not *he vístolo*) |

## Order: R I D

When there are several pronouns: **Reflexive → Indirect → Direct** (*se* always first):
- [[Me lo dio.]] (I → D)
- [[Se me olvidó.]] (se → I)
- [[Se lo dije.]] (*le → se* before lo)
- [[Pónselo.]] — Put it on him / her.

## Written accents

Attaching pronouns can move the stress past the second-to-last syllable, so add an accent to keep the original stress:
*di + me + lo* → [[dímelo]] · *comprando + lo* → [[comprándolo]] · *dar + se + lo* → [[dárselo]] · *siente + se* → [[siéntese]]
One pronoun on an infinitive usually needs no accent: *decirte, verlo*.

## Spelling changes with nosotros / vosotros commands

- *nosotros* commands drop **-s** before *nos* and *se*: *sentemos + nos* → [[sentémonos]], *digamos + se + lo* → [[digámoselo]]
- *vosotros* commands drop **-d** before *os*: *sentad + os* → [[sentaos]] (exception: *idos*)

## Leísmo, laísmo

In central Spain, people often say *le* for a male person as a direct object: [[Le vi ayer.]] (= *Lo vi ayer*) — this **leísmo** is accepted by the Academy for male persons. Using *la* for an indirect object (*La dije la verdad*) — **laísmo** — is considered incorrect.
