## Reflexive verbs

A reflexive verb has **-se** attached to the infinitive: [[levantarse]] (to get up), [[llamarse]] (to be called). The action "comes back" to the subject. Conjugate the verb normally and put the matching **reflexive pronoun** before it:

| | levantarse |
|---|---|
| yo | **me** levanto |
| tú | **te** levantas |
| él / ella / usted | **se** levanta |
| nosotros | **nos** levantamos |
| vosotros | **os** levantáis |
| ellos / ellas / ustedes | **se** levantan |

- [[Me levanto a las siete.]] — I get up at seven.
- [[¿A qué hora te acuestas?]] — What time do you go to bed?
- [[Mi hijo se ducha por la noche.]]
- [[Nos llamamos Ana y Luis.]] — Our names are Ana and Luis.

## Where does the pronoun go?

- **Before a conjugated verb**: [[Me ducho.]] [[No me ducho.]]
- **Attached to an infinitive or gerund** (or before the first verb — both are correct):
  [[Voy a ducharme.]] = [[Me voy a duchar.]] — I'm going to shower.
  [[Tienes que levantarte.]] = [[Te tienes que levantar.]]

## Daily routine vocabulary

| | |
|---|---|
| [[despertarse]] (e→ie) | to wake up — *me despierto* |
| [[levantarse]] | to get up |
| [[ducharse]] | to shower |
| [[lavarse]] los dientes / las manos | to brush one's teeth / wash one's hands |
| [[vestirse]] (e→i) | to get dressed — *me visto* |
| [[peinarse]] | to comb one's hair |
| [[acostarse]] (o→ue) | to go to bed — *me acuesto* |
| [[sentarse]] (e→ie) | to sit down — *me siento* |
| [[irse]] | to leave — *me voy* |

> With body parts Spanish uses **the**, not *my*: [[Me lavo las manos.]] — I wash my hands.

## Reflexive changes meaning

Some verbs mean something different with *se*: [[ir]] (to go) / [[irse]] (to leave); [[dormir]] (to sleep) / [[dormirse]] (to fall asleep); [[llamar]] (to call) / [[llamarse]] (to be called); [[quedar]] (to arrange to meet) / [[quedarse]] (to stay).
