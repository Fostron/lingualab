## Duration: llevar + time + gerund

**llevar** (any tense) **+ period of time + gerund** = *have been doing for*:
- [[Llevo tres años estudiando español.]] — I've been studying Spanish for three years.
- [[¿Cuánto tiempo llevas esperando?]] — How long have you been waiting?
- [[Llevaba dos horas conduciendo cuando paró.]]
- Negative: **llevar + time + sin + infinitive**: [[Llevo un mes sin fumar.]] — I haven't smoked for a month.

Alternatives: [[Hace tres años que estudio español.]] / [[Estudio español desde hace tres años.]]

## Gerund periphrases

| | |
|---|---|
| **seguir / continuar + gerund** — keep / still | [[Sigue lloviendo.]] [[¿Sigues trabajando allí?]] |
| **ir + gerund** — gradual progress | [[Voy entendiendo más.]] — I'm gradually understanding more. |
| **andar + gerund** — going around doing (often critical) | [[Anda diciendo mentiras.]] |
| **acabar + gerund** — to end up doing | [[Acabé aceptando.]] — I ended up accepting. |

## Infinitive periphrases

| | |
|---|---|
| **ponerse a + inf.** — start suddenly | [[Se puso a llorar.]] |
| **echarse a + inf.** — burst into | [[Se echó a reír.]] |
| **romper a + inf.** — break out | [[Rompió a llorar.]] |
| **estar a punto de + inf.** — be about to | [[Estaba a punto de salir.]] |
| **estar por + inf.** — be inclined to / yet to be done | [[Estoy por llamarla.]] |
| **llegar a + inf.** — go as far as | [[Llegó a decirme que me odiaba.]] |
| **dejar de + inf.** — stop | [[Deja de quejarte.]] |
| **no dejar de + inf.** — not fail to / keep | [[No deja de llamarme.]] |
| **volver a + inf.** — again | [[No vuelvas a hacerlo.]] |
| **tener + participle** — have (something) done | [[Tengo pensado viajar.]] [[Tengo escritas diez páginas.]] |
| **dar por + participle** — consider (as) | [[Lo dimos por perdido.]] |
