## Affirmative commands

**tú** (informal): the same as the *él/ella* form of the present:
hablar → [[¡Habla!]], comer → [[¡Come!]], escribir → [[¡Escribe!]]

**usted / ustedes** (formal): swap the vowel — -ar verbs take **-e / -en**, -er/-ir verbs take **-a / -an** (these are present subjunctive forms):

| | tú | usted | ustedes |
|---|---|---|---|
| hablar | habla | **hable** | **hablen** |
| comer | come | **coma** | **coman** |
| escribir | escribe | **escriba** | **escriban** |
| tener | **ten** | **tenga** | **tengan** |
| hacer | **haz** | **haga** | **hagan** |

The *usted* form is built from the **yo** form: *tengo → tenga, hago → haga, pido → pida, digo → diga, conozco → conozca*.

## Irregular tú commands

| | | | |
|---|---|---|---|
| decir → [[di]] | hacer → [[haz]] | ir → [[ve]] | poner → [[pon]] |
| salir → [[sal]] | ser → [[sé]] | tener → [[ten]] | venir → [[ven]] |

**vosotros** (Spain): replace -r of the infinitive with **-d**: [[hablad]], [[comed]], [[venid]].

## Pronouns attach to affirmative commands

[[¡Dímelo!]] (Tell me it!) [[Siéntese, por favor.]] [[Cómelo.]] [[Levántate.]] — add an accent to keep the original stress.
Reflexive *vosotros* drops the -d: *sentad + os → sentaos*.

> **Negative commands** (*don't…*) use a different form for *tú* (*¡No hables!*). They come at B1 with the subjunctive. Softer alternatives: [[¿Puedes cerrar la puerta?]] / [[¿Me pasas la sal?]]
