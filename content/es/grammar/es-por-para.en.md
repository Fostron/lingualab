Both often translate as *for*, but they look in different directions: **para** points **forward** to a goal or destination; **por** looks **back** at a cause, or describes the route / means / exchange.

## Para

| use | example |
|---|---|
| purpose (*in order to*) + infinitive | [[Estudio para aprender.]] |
| recipient | [[Este regalo es para ti.]] |
| destination | [[Salgo para Madrid.]] — I'm leaving for Madrid. |
| deadline | [[Lo necesito para el lunes.]] — by Monday |
| opinion | [[Para mí, es fácil.]] — In my opinion… |
| comparison with expectation | [[Para ser niño, habla muy bien.]] — for a child… |
| employer | [[Trabajo para una empresa alemana.]] |
| use of an object | [[una taza para café]] |

## Por

| use | example |
|---|---|
| cause, reason (*because of*) | [[Lo hago por ti.]] — I do it because of / for your sake. |
| through, along, around (movement) | [[Paseamos por el parque.]] [[Entró por la ventana.]] |
| approximate time / part of day | [[por la mañana]], [[por la noche]] |
| duration | [[Estudié por dos horas.]] (often just *dos horas*) |
| exchange, price | [[Lo compré por diez euros.]] [[Gracias por todo.]] |
| means of communication / transport | [[por teléfono]], [[por correo]], [[por avión]] |
| agent in the passive | [[escrito por Cervantes]] |
| per | [[cien kilómetros por hora]], [[dos veces por semana]] |
| on behalf of / in place of | [[¿Puedes trabajar por mí mañana?]] |

## Fixed expressions with por

[[por favor]] · [[por eso]] (that's why) · [[por fin]] (finally) · [[por ejemplo]] · [[por supuesto]] (of course) · [[por lo menos]] (at least) · [[por cierto]] (by the way) · [[por si acaso]] (just in case) · [[por qué]] (why) / **para qué** (what for)

> Quick test: if you can say *in order to* or *destined for*, use **para**. If you can say *because of, through, in exchange for, by*, use **por**.
