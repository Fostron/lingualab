Spanish uses many **verb + (preposition) + infinitive** combinations. They are extremely common in speech.

## Obligation

| | |
|---|---|
| **tener que** + inf. — to have to (personal) | [[Tengo que irme.]] |
| **hay que** + inf. — one must (impersonal) | [[Hay que reservar.]] — You have to book. |
| **deber** + inf. — must, should | [[Debes estudiar más.]] [[Deberías llamarla.]] (softer) |
| **necesitar** + inf. — to need to | [[Necesito descansar.]] |

## Beginning, ending, repeating

| | |
|---|---|
| **empezar a / comenzar a** + inf. — to start | [[Empezó a llover.]] |
| **ponerse a** + inf. — to start (suddenly) | [[Se puso a llorar.]] |
| **acabar de** + inf. — to have **just** done | [[Acabo de llegar.]] — I've just arrived. |
| **terminar de** + inf. — to finish doing | [[¿Has terminado de comer?]] |
| **dejar de** + inf. — to stop / quit doing | [[He dejado de fumar.]] |
| **volver a** + inf. — to do **again** | [[Vuelve a llamar.]] — Call again. |
| **seguir** + gerund — to keep doing | [[Sigue lloviendo.]] |

## Habits and plans

| | |
|---|---|
| **soler** (o→ue) + inf. — to usually do | [[Suelo cenar a las nueve.]] — I usually have dinner at nine. |
| **ir a** + inf. — going to | [[Vamos a ver.]] |
| **pensar** + inf. — to plan to | [[Pienso viajar en agosto.]] |
| **intentar / tratar de** + inf. — to try to | [[Intento aprender algo nuevo cada día.]] |

> **acabar de** in the imperfect = *had just*: [[Acababa de salir cuando llamaste.]]
