## Adjectives that change meaning

| adjective | with **ser** | with **estar** |
|---|---|---|
| aburrido | boring | bored |
| listo | clever | ready |
| malo | bad (character, quality) | ill; (food) gone off |
| bueno | good (person/thing) | tasty; (colloq.) attractive; healthy |
| rico | rich | delicious |
| verde | green | unripe; inexperienced |
| vivo | lively, sharp | alive |
| despierto | sharp, alert | awake |
| atento | considerate, polite | attentive (paying attention) |
| orgulloso | arrogant | proud (of something) |
| seguro | safe | sure, certain |
| católico | Catholic | (colloq., negated) well: *no estoy muy católico* |
| interesado | self-interested, mercenary | interested |
| cansado | tiring | tired |
| abierto | open-minded | open |

- [[Mi hermano es muy listo.]] / [[¿Estás listo?]]
- [[Este barrio es seguro.]] / [[¿Estás seguro?]]
- [[La paella está muy rica.]] / [[Su familia es rica.]]
- [[El plátano está verde.]]

## Same adjective, different perspective

With many adjectives both are possible: **ser** presents the quality as a characteristic, **estar** as a change, a subjective impression or a temporary state.
- [[Es guapa.]] — She's pretty. / [[¡Qué guapa estás hoy!]] — You look pretty today!
- [[Es delgado.]] — He's slim (by nature). / [[Estás más delgado.]] — You've lost weight.
- [[El café es caro aquí.]] / [[¡Qué caro está todo!]] — How expensive everything has got!

## Other key distinctions

- **Events take ser** for location: [[El concierto es en el estadio.]]
- **Death**: [[Está muerto.]] (state, despite being permanent)
- **Marital status**: [[Es soltero]] / [[Está casado]] — both are used.
- **Prices that change**: [[¿A cuánto están los tomates?]]
- **estar de** + noun = temporary role or state: [[Está de camarero este verano.]] [[Estamos de vacaciones.]] [[Estoy de mal humor.]]
- **estar para / por**: [[No estoy para bromas.]] — I'm not in the mood for jokes.
