## Tener — to have

| | |
|---|---|
| yo **tengo** | nosotros **tenemos** |
| tú **tienes** | vosotros **tenéis** |
| él / ella / usted **tiene** | ellos / ellas / ustedes **tienen** |

*Tener* is irregular: **tengo** in the *yo* form, and **e → ie** in the stressed forms (*tienes, tiene, tienen*).

- [[Tengo dos hermanos.]] — I have two brothers.
- [[¿Tienes coche?]] — Do you have a car?
- [[No tenemos tiempo.]] — We don't have time.

## Age: tener … años

Spanish *has* years: [[Tengo veinte años.]] — I'm twenty. [[¿Cuántos años tienes?]] — How old are you?

## Expressions with tener (English uses "to be")

| Spanish | English |
|---|---|
| [[tener hambre]] | to be hungry |
| [[tener sed]] | to be thirsty |
| [[tener frío]] / [[tener calor]] | to be cold / hot (a person) |
| [[tener sueño]] | to be sleepy |
| [[tener miedo]] (de) | to be afraid (of) |
| [[tener razón]] | to be right |
| [[tener prisa]] | to be in a hurry |
| [[tener suerte]] | to be lucky |
| [[tener cuidado]] | to be careful |
| [[tener ganas de]] + inf. | to feel like doing |

These are **nouns**, so "very" is **mucho/mucha**, not *muy*: [[Tengo mucha hambre.]] [[Tengo mucho frío.]]

## Tener que — to have to

**tener que + infinitive** = to have to (obligation): [[Tengo que trabajar.]] — I have to work. [[¿Tienes que irte?]] — Do you have to go?
